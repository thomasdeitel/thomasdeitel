## Featured project: Under the Radar

### Navy Atmosphere Radar Forecaster · UC San Diego i4NS

Through Innovating for National Security, I built an atmospheric duct prediction and radar propagation prototype with public NOAA observations. It combines weather-data pipelines, neural-network and gradient-boosting models, reliability indicators, and an offline workflow for operators to retrain on their own data.

**[Explore the repository →](https://github.com/thomasdeitel/under-the-radar-mvp)** · **[Project overview and results →](https://thomasdeitel.github.io/portfolio/projects/navy-atmospheric-forecasting/)**

![Prototype propagation map using a public NOAA sounding](https://raw.githubusercontent.com/thomasdeitel/under-the-radar-mvp/main/results/coverage_example.png)

The public prototype uses no Navy data. It has not been validated against a Navy simulator or deployed operationally. Evaluation methods and limitations are documented in the repository.
